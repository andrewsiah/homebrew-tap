# andrewsiah/homebrew-tap

Homebrew formulae for Andrew Siah's tools.

```bash
brew tap andrewsiah/tap
brew install --HEAD andrewsiah/tap/openfusion   # latest main
brew install andrewsiah/tap/openfusion          # stable v0.1.0
```

- **openfusion** — Devin-Fusion-style orchestration on the AI subscriptions you already pay for. https://github.com/andrewsiah/openfusion
